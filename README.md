<details>
  <summary>Yapping about my love with C++</summary>
  
I think I felt in love with the freedom C++ gives: when I occasionally go back to Java I am occasionally missing this ability of controlling every bit (pun not intended) of my program. I mean, putting aside the compiler optimisations (I can't predict them with my current skills, that's some magic tricks) and some surely mystical C++ features, it is a pretty straightforward language. And that's without mentioning C: from my short experience with it, there is no simpler language. The difficulty stands from how to use the simple set of features it gave us to create a program that will run, and not segfault. I'd say it's more accurate to say it has to do with management/architecture design skill more than any other language.
</details>
